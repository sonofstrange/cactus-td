# 🌵 Cactus Tower Defense: Remastered

Обновлённая версия игры Cactus Tower Defense с процедурной пиксельной графикой, магазином мета-прогрессии за Звёздные Кактусы и новыми боевыми башнями.

## 🚀 Запуск игры
```bash
python main.py
```
*(Не требует внешних картинок или звуков — игра генерирует все пиксельные текстуры процедурно при запуске!)*

## 🎮 Управление и горячие клавиши

### В Главном Меню (Выбор Карты):
- **Клик мыши по карте** — выбрать уровень.
- **`<` / `>` на селекторе стартовой волны** — выбор волны для старта (шаг 5 волн, доступно при покупке улучшения №6 и наличии рекорда).
- **`[U]` или клик по кнопке вверху** — открыть **Магазин Звёздных Кактусов**.
- **`[ПРОБЕЛ]`** — начать бой.

### В Магазине Улучшений:
- **Клик по кнопке «КУПИТЬ»** — прокачать выбранное улучшение за Звёздные Кактусы.
- **`[ESC]` / `[U]` / Кнопка «Назад»** — вернуться к выбору карт.

### В Бою:
- **`[1]`** — Выбрать **Магическую башню** (100 🌵).
- **`[2]`** — Выбрать **Огненную / Каменную башню** (200 🌵, наносит урон по площади).
- **`[3]`** — Выбрать **Башню Заморозки** (150 🌵, доступна после покупки в магазине).
- **`[4]`** — Выбрать **Палатку Солдат** (220 🌵, призывает кактус-рыцарей, доступна после покупки в магазине).
- **`[U]`** — Режим улучшения: кликайте по башням на карте для прокачки за кактусы.
- **`[ПРОБЕЛ]` или клик по плашке скорости в правом нижнем углу** — мгновенное переключение скорости: `1X ➔ 2X ➔ 3X ➔ 4X ➔ 5X ➔ 1X`.
- **`[R]`** — Выйти из боя и вернуться в Главное Меню с сохранением прогресса.

## 🌟 Список улучшений за Звёздные Кактусы:
1. **Лимит Ускорения**: открывает скорости `3x` (за 3 ⭐), `4x` (за 10 ⭐) и `5x` (за 30 ⭐). Ускорение работает мгновенно и без рассинхронизации.
2. **Стартовый уровень башен**: новые башни сразу ставятся с уровнем от 2 до 8 (цены: 2, 4, 7, 12, 20, 30, 40 ⭐).
3. **Башня Заморозки (10 ⭐)**: замедляет врагов в радиусе и вешает «Обледенение». Огненная башня наносит по замороженным врагам **+75% повышенного урона**!
4. **Палатка Солдат (10 ⭐)**: призывает на дорогу кактус-рыцарей, блокирующих мобов:
   - Урон по солдатам: `mob1: 1`, `mob2: 2`, `mob3: 3`, `boss: 10`, `миньоны (51, 52, 53): 2, 4, 6`.
5. **Макс. уровень башен**: повышает предельный уровень прокачки башен в бою (формула цены: `(2 + lvl) * lvl^1.3`).
6. **Выбор стартовой волны**: шаг 5 волн за уровень (цена: `3 + 3 * lvl`). При старте с высокой волны игрок получает стартовые кактусы на расстановку обороны.
